# IS201

## Training

[`training/`](training/) — **Ground Contact**, an elastic-athlete training app: a periodised
year built on the UFA game model, 95 exercises with full how-tos, a gym/no-equipment
mode toggle, isometric and rehab
protocols for the adductor / hamstring / labrum, a test battery with trend charts, and a
built-in interval timer. Runs entirely in the browser; state saves to the device.
